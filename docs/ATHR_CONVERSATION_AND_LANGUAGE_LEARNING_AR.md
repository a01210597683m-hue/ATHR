# تجربة المحادثة والتعلم الصوتي في ATHR

## مواصفات معتمدة
1. جميع مساحات المحادثة، دون استثناء، تستخدم واجهة محادثة كبيرة Full-screen / conversation-first تشبه تطبيقات المحادثة الحديثة. لا تُحصر المحادثة في نافذة صغيرة داخل لوحة مزدحمة.
2. تعلم اللغات يقدم مدرس/رفيق ذكاء اصطناعي احترافيًا وودودًا، بالصوت والكتابة، مع ممارسة محادثة تفاعلية، تصحيح لطيف للأخطاء، تدريب نطق، مفردات، ومستويات وخطة تقدم.
3. دعم محادثة صوتية مباشرة بنمط اتصال صوتي فقط (voice-only). لا مكالمات فيديو، ولا تشغيل كاميرا أو التقاط فيديو داخل المحادثة.
4. دعم الرسائل الصوتية المسجلة (Voice Notes): تسجيل وإرسال واستقبال وتشغيل، مع تحويل الصوت إلى نص (Speech-to-Text) وإمكانية تحويل الرد المكتوب إلى صوت (Text-to-Speech).
5. السماح برفع الصور والملفات المرئية التي يختارها المستخدم من الجهاز، وتحرير الصور وتوليد الصور وGIF. لا يسمح برفع أو إرسال ملفات فيديو داخل المحادثة، ولا يعني دعم الصور فتح الكاميرا أو إضافة مكالمات فيديو.
6. دعم النص والصوت في كل مساحات الشات، وليس المساعد العام فقط، مع الاحتفاظ بسياق المحادثة وسجلها.

## UX
- مساحة الرسائل هي العنصر الرئيسي وتمتد تقريبًا لكامل الشاشة.
- حقل كتابة واضح وثابت أسفل المحادثة مع أزرار مرفقات وصوت وإرسال.
- في وضع الاتصال الصوتي: شاشة صوتية بسيطة بأزرار كتم/إنهاء، ومؤشر حالة الاتصال؛ لا أي عنصر كاميرا.
- عرض التسجيل الصوتي كموجة/شريط تشغيل مع المدة وإمكانية تشغيله وإيقافه.
- النص المستخرج من التسجيل قابل للمراجعة قبل الإرسال عند اختيار المستخدم.
- تعلم اللغة يتكيف مع مستوى المتعلم واللغة المستهدفة، ويجعل التصحيح مشجعًا وغير محرج.

## قيود خصوصية وتشغيل
- طلب أذونات الميكروفون فقط عند بدء ميزة صوتية، وشرح سبب الإذن.
- لا تطلب إذن الكاميرا، ولا تنشئ تدفق فيديو أو رفع فيديو من شاشة المحادثة.
- توضيح حالة التسجيل، والتحكم في إيقافه وحذفه.
- لا تبدأ مكالمة أو تسجيلًا تلقائيًا دون فعل واضح من المستخدم.

## خطة التنفيذ
1. تحويل كل واجهات المحادثة إلى تخطيط كامل الشاشة مع الحفاظ على التنقل الحالي.
2. إضافة تسجيل الرسائل الصوتية ورفعها وتشغيلها.
3. إضافة Speech-to-Text وText-to-Speech.
4. بناء تجربة تعلم اللغات الصوتية والكتابية وتصحيح النطق.
5. تنفيذ اتصال صوتي حي (WebRTC أو بنية صوتية متدفقة مناسبة) دون مسار فيديو.
6. اختبار Android والشاشات الصغيرة وإمكانية الوصول والأذونات.

## حالة التنفيذ
هذه مواصفات تطوير معتمدة أُضيفت إلى خطة ATHR؛ لا تعني أن ميزات الصوت الحي أو تحويل الكلام أو واجهات الشات الكاملة أصبحت منشورة بالفعل.
