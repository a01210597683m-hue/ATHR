# ATHR — Product Foundation

## Vision
Build a global, Arabic-first intelligent ecosystem that helps people understand, learn, create, plan, and grow — turning ideas into lasting impact.

## Non-negotiable product boundaries
- ATHR is not a game platform. No game lobby, game rewards, sports modes, levels, or game-style progression.
- The interface may feel alive through subtle motion, ambient light, responsive transitions, and evolving visual environments; motion must never obstruct usability.
- The product must be accessible, calm, readable, responsive, and usable on mobile.

## Core experience areas
1. Central AI assistant
2. Specialized intelligence capabilities
3. Learning and personal development
4. Creative studio
5. Personal wellbeing assistant (AI support, not a replacement for licensed clinical care)
6. Projects and ideas workspace
7. Adaptive interactive worlds for exploration, knowledge, and learning

## Brand direction
- Brand: ATHR (أثر)
- Meaning: a lasting trace / meaningful impact
- Tagline: Beyond Intelligence. Into Possibility.
- Visual language: deep indigo, midnight navy, champagne gold, violet, and cyan accents; glass-like layers; restrained luminous motion.

## Delivery stages
1. Design system and responsive front-end prototype
2. Arabic/English localization foundation and language learning UX
3. Authentication and secure data model
4. AI provider integration and specialized capability routing
5. User testing, accessibility, performance, and release readiness

## Current status
The repository contains an initial animated UI prototype and product documentation. Production AI, authentication, persistence, and backend services are not yet implemented.
